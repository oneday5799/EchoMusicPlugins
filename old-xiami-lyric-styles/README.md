# old-xiami-lyric-styles

将 EchoMusic 歌词页替换为旧版虾米歌词风格皮肤。

从 1.1.0 起，插件从 `lyricEffects` 叠加装饰层方式改造为 `lyricsPage` 完整歌词页皮肤（参考 `apple-music-style` 的皮肤架构）：插件自行渲染歌词行，不再依赖宿主歌词 DOM。启用插件后首次打开歌词页会自动选中该皮肤，也可以在换肤面板中手动切换。

## 效果

- 页面样式可选：普通模式（左侧封面+歌曲信息，与宿主内置"封面"模式一致）或简洁模式（仅歌词）
- 逐字歌词双色高亮：当前行已唱的字为主题色，未唱到的字保持纯白，按字符时间轴逐帧刷新（与宿主同一机制）
- 当前行辉光跟随字色连续过渡：逐字字符由「宽辉光 + 近辉光 + 清晰文字」三层叠加，三层共用同一渐变进度；辉光进度前倾且有起唱下限，字一起唱就有主题色辉光（卡拉OK的"点亮"手感），未播侧的辉光极淡以免白色盖过主题色
- 非逐字歌词的当前行整体视作已唱，使用主题色 + 主题色辉光
- 其他行渐隐，随距离增加透明度和模糊递增
- 左侧当前行指示器（圆点/竖线）
- 弹簧滚动跟随，滚轮浏览 5 秒后自动恢复
- 当前行超长时横向跑马灯滚动
- 封面模糊背景，底部复用宿主播放控制栏（含弹幕入口）
- 双击歌词行跳转播放位置，滚轮浏览时显示时间标签
- 翻译/音译副行显示（跟随宿主右侧工具按钮的开关，逐字行副歌词同样逐字高亮）
- 尊重系统"减少动态效果"偏好

## 设置

配置保存在宿主皮肤配置中，在"插件设置"或换肤面板的皮肤设置里修改即时生效。

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 歌词颜色 | 分别设置已播与未播的字色（含辉光），可选「跟随封面取色」；留空则跟随默认 | 已播=主题色，未播=纯白 |
| 页面样式 | 普通模式（显示封面）/ 简洁模式（仅歌词） | 普通模式 |
| 标记样式 | 当前行指示器：圆点/竖线/无 | 竖线 |
| 对齐方式 | 左对齐/居中对齐 | 左对齐 |
| 字号 | 50-200% | 150% |
| 字重 | 300-900，副行随主行自动减细 | 760 |
| 当前行放大 | 100-150 | 115 |
| 辉光强度 | 0-80 | 9 |
| 其他行透明度 | 20-80 | 45 |
| 滚动过渡 | 100-1200ms | 420 |
| 行间距 | 1.5-5.0 | 2.1 |
| 歌词边距 | 0-288 | 144 |
