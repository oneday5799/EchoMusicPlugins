# 鼠标手势控制

通过鼠标手势控制 EchoMusic 的播放、导航和滚动。

## 功能

- 支持左键和右键手势
- 支持方向滑动（上、下、左、右）
- 支持对角线滑动（/ 和 \）
- 支持画圈手势识别
- 支持按住鼠标按键滚动滚轮
- 可自定义手势与功能的映射
- 可调节手势灵敏度
- 可显示手势轨迹线（可自定义颜色和宽度）

## 默认手势映射

| 手势 | 功能 |
|------|------|
| 左键 ↓ 向下 | 下一曲 |
| 左键 ↑ 向上 | 上一曲 |
| 左键 → 向右 | 前进 |
| 左键 ← 向左 | 后退 |
| 左键 / 对角 | 禁用 |
| 左键 \ 对角 | 禁用 |
| 左键 ○ 画圈 | 暂停/播放 |
| 左键 滚轮↓ | 快速到底 |
| 左键 滚轮↑ | 禁用 |
| 右键 ↓ 向下 | 下一曲 |
| 右键 ↑ 向上 | 上一曲 |
| 右键 → 向右 | 前进 |
| 右键 ← 向左 | 后退 |
| 右键 / 对角 | 禁用 |
| 右键 \ 对角 | 禁用 |
| 右键 ○ 画圈 | 暂停/播放 |
| 右键 滚轮↓ | 快速到顶 |
| 右键 滚轮↑ | 禁用 |

## 手势说明

- **/** ：从左下到右上的对角线滑动
- **\\** ：从左上到右下的对角线滑动

## 可用操作

- `下一曲` - 播放下一首歌曲
- `上一曲` - 播放上一首歌曲
- `暂停/播放` - 切换播放状态
- `前进` - 页面导航前进
- `后退` - 页面导航后退
- `快速到顶` - 滚动到页面顶部
- `快速到底` - 滚动到页面底部
- `禁用` - 禁用该手势

## 设置说明

- **显示轨迹线**：开启/关闭手势轨迹显示（默认开启）
- **轨迹颜色**：跟随主题色或自定义颜色（默认跟随主题色）
- **轨迹宽度**：轨迹线宽度，1-10px（默认 3px）
- **最小滑动距离**：触发方向手势所需的最小像素距离（默认 50px）
- **画圈检测阈值**：判定为画圈的最小角度变化（默认 300°）
- **对角线灵敏度**：判定为对角线的角度容差（默认 40%）
- **手势映射**：为每个手势配置对应的操作
