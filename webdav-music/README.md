# WebDAV 音乐

连接 WebDAV 服务器，浏览和播放云端音乐文件。

## 功能

- **🎵 云端音乐浏览**：通过 WebDAV 协议浏览远程服务器上的音乐文件，支持目录导航和面包屑路径
- **📋 平铺展示**：开启后递归扫描所有子目录，将全部音乐集中展示在一个列表中，扫描进度在任务中心实时显示
- **▶️ 播放控制**：支持双击播放单曲、播放全部、点击文件夹播放按钮一键播放整个文件夹
- **🏷️ 元数据提取**：自动读取音频文件的嵌入标签（ID3v2 / FLAC），获取标题、歌手、专辑、封面图和歌词
- **🖼️ 封面展示**：优先读取嵌入封面，其次探测目录下的封面文件（cover.jpg、folder.jpg 等），兜底跟随主应用默认封面
- **📁 文件夹管理**：支持多层目录结构，文件夹与歌曲混合排序显示
- **🔐 认证支持**：支持 Basic Auth 用户名/密码认证

## 安装

将插件文件夹 `webdav-music` 放入 EchoMusic 的插件目录中即可。

```
EchoMusicPlugins/
└── webdav-music/
    ├── manifest.json
    ├── icon.svg
    ├── index.js
    └── style.css
```

## 使用

1. 在插件设置中填写 WebDAV 服务器地址、用户名、密码和根目录路径
2. 点击左侧边栏的「WebDAV」进入浏览页面
3. 双击歌曲即可播放，双击文件夹进入子目录
4. 点击文件夹左侧的播放按钮可直接播放文件夹内全部音乐

## 设置

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 服务器地址 | WebDAV 服务器 URL，如 `https://webdav.example.com` | - |
| 用户名 | Basic Auth 用户名，留空表示无需认证 | - |
| 密码 | Basic Auth 密码 | - |
| 根目录路径 | 浏览音乐的起始路径 | `/` |
| 平铺展示 | 开启后递归扫描所有子目录，集中展示全部音乐，扫描进度在任务中心显示 | 关闭 |
| 在线匹配封面歌词 | 开启后使用酷狗搜索出的封面和歌词，关闭则优先使用歌曲内嵌的封面和歌词 | 关闭 |

> 双击播放的行为跟随主应用「播放队列模式」设置：上下文模式会用当前目录 / 平铺列表替换队列，单曲模式只播放该曲。

## 浏览视图

| 视图 | 列表实现 | 说明 |
|------|---------|------|
| 平铺展示 | 宿主 `SongList` / `SongListHeader` | 虚拟滚动（万首库流畅）、宿主右键菜单（立即播放 / 下一首 / 排队候播 / 添加到 / 分享）、宿主搜索过滤、点击表头排序。可排序列为「# / 歌曲 / 专辑」 |
| 文件夹浏览 | 插件自绘 | 需要在同一列表里混排文件夹与歌曲，宿主 `SongList` 不支持。可按「# / 歌曲 / 大小」排序 |

两种视图的排序状态相互独立：目录视图的「大小」排序在切到平铺视图时会被清空（宿主表头没有大小列）。

## 支持的音频格式

`mp3` `flac` `wav` `aac` `ogg` `wma` `m4a` `ape` `opus` `aiff` `alac` `dsf` `dff`

## 歌曲命名格式

插件通过文件名解析歌曲标题和歌手，支持以下命名格式（按优先级匹配）：

| 格式 | 示例 | 解析结果 |
|------|------|----------|
| `歌手 - 标题` | `周杰伦 - 晴天.mp3` | 歌手：周杰伦，标题：晴天 |
| `歌手 – 标题`（短横线 en-dash） | `Taylor Swift – Shake It Off.mp3` | 歌手：Taylor Swift，标题：Shake It Off |
| `歌手 — 标题`（长横线 em-dash） | `Adele — Hello.flac` | 歌手：Adele，标题：Hello |
| `编号. 歌手 - 标题` | `01. 林俊杰 - 江南.mp3` | 歌手：林俊杰，标题：江南 |
| `编号- 歌手 - 标题` | `02-陈奕迅-十年.mp3` | 歌手：陈奕迅，标题：十年 |

> 编号前缀为行首的 `数字` 后跟 `.`、`-` 或空格，解析时会自动去除。
> 如果文件名不符合上述格式，则整个文件名（不含扩展名）作为标题，歌手显示为「未知歌手」。
> 若音频文件包含内嵌标签（ID3v2 / FLAC），解析后会以嵌入标签为准覆盖文件名解析结果。

## 封面与歌词获取

插件支持两种封面和歌词获取模式，可在插件设置中切换：

### 关闭「在线匹配封面歌词」（默认）

优先使用歌曲内嵌数据，缺少时通过酷狗 API 补充：

1. 音频文件内嵌封面和歌词（ID3v2 / FLAC 标签）
2. 目录下的封面图片文件（cover.jpg、folder.jpg 等）
3. 酷狗 API 搜索补全缺失的封面或歌词
4. 主应用兜底封面（跟随 `cover-fallback` 插件设置动态切换）

### 开启「在线匹配封面歌词」

优先使用酷狗搜索结果，不保证封面和歌词的准确性：

1. 酷狗 API 搜索结果中的封面和歌词
2. 音频文件内嵌数据补充酷狗未提供的字段
3. 主应用兜底封面（跟随 `cover-fallback` 插件设置动态切换）

## 诊断

排查性能问题时，先在 DevTools Console 里核对这两条日志：

| 时机 | 日志 | 用途 |
|------|------|------|
| 插件启用 | `[webdav-music] v1.5.0 已启用 (id=webdav-music)` | 确认新代码已在运行（插件自 v1.1.3 起只保留 error/warn，无日志不代表未加载） |
| 打开批量面板 | `[webdav-music] 批量面板打开：条目 N，首屏渲染 M 行，视口 Hpx` | 核对窗口化是否生效：`M` 应远小于 `N`（一般 20-40 行） |

若 `M` 接近 `N`，说明窗口化未生效，请附上这条日志的具体数值。

## 权限说明

插件在 `manifest.json` 中声明了以下 capability：

| 能力 | 用途 |
|------|------|
| `audioSource` | 接管 WebDAV 歌曲的播放地址，动态拼接认证 URL |
| `kugouApi` | 在线匹配封面与歌词（可在设置中关闭） |
| `lyrics` | 注册歌词解析器，支持内嵌歌词与手动选择歌词 |
| `unrestrictedNetwork` | WebDAV 需要 `PROPFIND` 等非标准方法并访问用户自定的内网地址，浏览器 Fetch 受 CORS 与禁止请求头限制，因此走主进程网络能力 |

> **注意**
> 出于浏览器 `<audio>` 标签无法附加请求头的限制，播放地址会把 Basic Auth 凭证内嵌在 URL 中（`https://user:pass@host/...`）。该地址会保存在播放队列与播放历史中，请勿在不受信任的共享设备上使用需要认证的库。

- MP3 帧长公式把「码率 + 采样率 + padding」复合位当采样率除数，且缺少采样率查找表；补上 `samplesPerFrame` 与分版本采样率表

- 修复音质缓存对「探测过但无音质信息」的文件不生效（ogg/opus/wma 每次播放重发 256KB Range 请求）
- 修复快速连续切换目录时旧响应覆盖新目录内容（补加载令牌）

- 修复批量抽屉开关卡顿：宿主 `.drawer-panel` 默认带 `backdrop-filter`（`Drawer.vue:133-134`）且开关时过渡 `opacity` 与 `transform`（`Drawer.vue:139-145`），背景模糊的代价与面板**面积**成正比而非行数；插件已用不透明底色覆盖默认背景，故在 `panelStyle` 里关闭该滤镜
