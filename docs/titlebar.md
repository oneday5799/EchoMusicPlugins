# 标题栏 API

`ctx.ui.titlebar.register()` 注册一个标题栏操作，宿主统一负责顶栏按钮、更多菜单、Tooltip、键盘交互和用户布局管理。插件无需挂载标题栏 DOM。

这是破坏性 API 调整：旧的 `ctx.ui.moreMenu.addItem()` 已移除，没有兼容入口。使用旧接口的插件需更新调用；缺少图标的旧入口也必须补上 `icon`。

## 注册操作

```ts
const dispose = ctx.ui.titlebar.register({
  id: 'open-tools',
  title: '插件工具',
  icon: 'tabler:tools',
  tooltip: '打开插件工具',
  defaultPlacement: 'more', // 'toolbar'：顶栏；'more'：更多菜单
  order: 100,
  visible: () => true,
  disabled: () => false,
  onClick: async () => {
    // 打开插件页面或执行操作。
  },
});

// 可主动注销；插件停用时宿主也会自动清理。
// dispose();
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 插件内稳定且唯一的操作 ID。不要因名称或版本变更而更换 ID，否则用户布局无法匹配。 |
| `title` | 是 | 更多菜单和无障碍名称。 |
| `icon` | 是 | Iconify 名称（如 `tabler:tools`）或图标数据对象，与侧边栏格式一致。即使默认在更多，也需要图标，因为用户可移到顶栏。 |
| `tooltip` | 否 | 默认为 `title`，由应用 Tooltip 组件呈现，不使用浏览器原生 `title`。顶栏朝下显示；更多菜单已有完整名称，只有与名称不同的说明才显示额外提示。 |
| `defaultPlacement` | 否 | `'toolbar'` 或 `'more'`，默认为 `'more'`。只决定初始位置，不能覆盖用户设置。 |
| `order` | 否 | 默认 1000，数值越小越靠前；用户排序优先。同值以稳定操作标识确定顺序。 |
| `visible` | 否 | 布尔值或同步函数，默认 `true`。函数可读取 Vue 响应式状态；异常时隐藏。 |
| `disabled` | 否 | 布尔值或同步函数，默认 `false`。函数可读取 Vue 响应式状态；异常时禁用。 |
| `onClick` | 是 | `() => void \| Promise<void>`。异步执行期间禁用该操作，防止重复触发；异常交给插件运行时错误处理。 |

`visible` 和 `disabled` 函数应无副作用。注册后更新响应式状态即可改变可见性或可用性；如果需更改标题、图标等描述，使用相同 ID 重新注册。

## 位置与用户管理

标题栏的「更多应用」弹出层（下文称更多菜单）直接在每项右侧提供图钉，点击即可固定到顶栏或取消固定，不关闭弹层也不执行该项功能。用户可拖动菜单项左侧图标排序，也可直接拖动顶栏按钮；修改即时生效并自动保存，右上角提供「恢复默认」。菜单操作聚焦后可按 Alt + 上下方向键排序。

- 内置听歌识曲和任务中心默认在搜索框右侧，一起听默认在更多。
- 固定到顶栏的内置及插件操作统一排列在搜索框右侧，按保存顺序混合排序；更多菜单列出全部可见操作，更多按钮保持在顶栏右侧。
- 已固定的操作仍在更多菜单中显示，便于取消固定。窗口较窄时，放不下的顶栏按钮临时隐藏，操作仍可从更多菜单执行；窗口恢复后自动回到顶栏，保存的位置和顺序不变。
- 布局按插件 ID 与操作 ID 隔离。插件停用时移除入口，但保留用户偏好；重新启用或升级后恢复。
- `visible: false` 的操作在顶栏和更多菜单中均隐藏，但保留用户偏好；图钉不会改变插件运行状态。
- 恢复默认会清除标题栏的用户位置和排序偏好，重新采用每个操作的 `defaultPlacement` 和 `order`。
- 后退、前进、刷新、搜索、Mini、平台窗口控制以及「更多」本身不属于可移动操作。

## 生命周期与迁移

同一插件重复注册同一 ID 会替换旧操作；旧注册返回的注销函数不会删除新操作。已注销或已替换操作的旧回调无法再执行。插件停用、卸载时自动移除注册，正在执行的 Promise 不会被强制取消。

迁移时将 `ctx.ui.moreMenu.addItem({...})` 改为 `ctx.ui.titlebar.register({...})`，补上必填 `icon`，按需填写 `defaultPlacement` 和 `tooltip`。不要同时保留旧接口调用，也不要自行往标题栏插入按钮或用 `title` 属性提供悬停提示。
